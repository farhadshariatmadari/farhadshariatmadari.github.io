// context & role

An end-to-end e-commerce site-maker — merchant panels for products, collections, customers, and orders — built in-house from scratch, with crypto-commerce support.

Backed by the Greek government with the explicit goal of becoming Greece's homegrown Shopify alternative. I lead product design across the merchant-facing panels: table views, record management, forms, and bulk actions — the operational heart of a commerce back office.

// problem

Replace Shopify — build the back office it took years to earn.

A national alternative to Shopify has to match the operational depth merchants expect: dense table views, fast record management, forms and bulk actions that hold up under real catalog sizes — plus first-class crypto-commerce. All of it built in-house from scratch.

// approach

A mature two-tier system, wired straight to code.

01

Own a mature two-tier design system

03
Handoff through Figma → GitHub, Code Connect live

Design tokens map 1:1 to the Tailwind / shadcn code implementation, with Code Connect in active use.
